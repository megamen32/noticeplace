# Universal Outbox positioning

Status: work

## Original request

Не переименовывать NoticePlace; позиционировать его как Universal Outbox for
AI-to-human attention и связать его с отдельным Universal Inbox.

## Objective

Clarify the outbound/inbound relationship between NoticePlace and Universal
Inbox through reciprocal public README links.

## Business canary

Both public repositories link to each other and explain the direction of the
flow: NoticePlace sends AI attention outward; Universal Inbox receives and
organizes incoming human-facing conversations.

## Confirmed scope

- NoticePlace remains named NoticePlace.
- Public positioning uses “Universal Outbox for AI-to-human attention”.
- Reciprocal links in both README files, in English/Russian/Chinese where applicable.

## Explicit exclusions

- No repository rename.
- No API, hostname, service, or CLI changes.
