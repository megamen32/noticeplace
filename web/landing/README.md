# Notice Place: public landing

Approved dark/orange interactive design. Original HTML, CSS, Canvas animation,
JavaScript demo and SVG mark are maintained here, not in a separate repository.
No framework, CDN, tracker, external font or backend request is required.

- `index.html`, `styles.css`, `app.js`: editable sources.
- `assets/mark.svg`: original vector mark (no font file).
- `build.py`: standard-library-only standalone build.
- `dist/NoticePlace.html`: committed public artifact.

Build from the repository root:

```sh
python3 web/landing/build.py
python3 -m pytest -q tests/test_public_landing.py
```

Commit both sources and rebuilt HTML. The build is deterministic and tests check
that it reproduces the committed artifact without changing the modular markup.
Source imported from the user-approved `NoticePlace-code.zip` on 2026-10-14;
original standalone HTML SHA-256:
`a07b1f99c72500f7c3812c48157f2f6517fd6e5845952609a1458528dfe22cde`.

The demo is explicitly fictional and runs in the visitor's browser. Its buttons
never create real incidents, contact servers, run agents or send notifications.
The console link remains `https://notify.bezrabotnyi.com/admin/` behind existing
SSO. Public API and health endpoint authorization are unchanged.

The main title uses original SVG geometry generated by `build.py`. Other text
uses system fonts. No font files or generated mockup images are embedded.
The page supports mobile layouts, keyboard interaction, reduced motion and an
animation pause. It uses no persistent storage.

## Production publication

See [deployment and rollback](../../docs/public-landing.md).
Nginx serves only the exact public `/` from an immutable, committed HTML release.
The monitored services, mesh processes and API runtime are not redeployed.
The old unused `notification_center/landing.py` is not this page's source.
